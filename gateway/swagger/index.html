НетДосуга API

Для защищённых операций сначала выполните POST /api/v1/auth/login через Try it out. Браузер сохранит HttpOnly cookie nd_session и отправит её при следующих запросах. POST /api/v1/auth/logout завершает сессию. Вручную вводить cookie в Authorize не требуется.

Локальная демонстрация: платежи и возвраты имитируются. Открыть кассу · Контракт OpenAPI (JSON) · Swagger UI: Apache-2.0, NOTICE
